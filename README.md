# TaskFlow — Об'єктна модель керування завданнями (ЛР № 2)

**Варіант № 6:** Польове дослідження

## Опис предметної області
Застосунок призначений для керування процесом збору та опрацювання анкет соціологічного/маркетингового польового дослідження.

* **Користувач (`User`):** Дослідник або керівник проєкту (має унікальний `id` та ім'я).
* **Проєкт (`Project`):** Польове дослідження (наприклад, "Опитування мешканців міста щодо міського транспорту").
* **Завдання (`Task`):** Конкретний етап опрацювання анкет (наприклад, "Збір анкет у центральному районі").
* **Правило завершення (`VariantPolicy`):** Завдання вважається виконаним, якщо опрацьовано щонайменше 8 анкет ($u \ge 8$), причому сумнівні анкети відсутні ($d = 0$), АБО є офіційний дозвіл керівника прийняти сумнівні анкети ($a = true$).

## Схема зв'язків та незмінність (Immutability)
* `User` — незмінний (`id`, `name` позначено як `final`). Порівняння `equals` відбувається виключно за `id`.
* `Project` — незмінний (`id`, `title`, `owner` є `final`).
* `Task` — містить незмінні поля (`id`, `title`, `project`, `created`, `dueDate`, `policy`) та змінні поля стану (`status`, `assignee`).
* **Життєвий цикл статусів:** `NEW` -> `ACTIVE` -> `DONE`.
